# Services Required

## Azure Event Grid Event-Driven Automation

The following Azure services are required to complete the project.

### 1. Azure Event Grid

**Role:** Event detection and routing.

Azure Event Grid receives events generated by Azure resources and routes
the events to the appropriate event handler or subscriber.

**Purpose in this project:**
- Detect events.
- Route events to the required handler.
- Support event-driven automation.

---

### 2. Azure Functions

**Role:** Event processing and automation.

Azure Functions processes the events received from Azure Event Grid and
executes the required automation logic.

**Purpose in this project:**
- Receive Event Grid events.
- Process incoming events.
- Execute the required automation task.
- Handle event-processing logic.

---

### 3. Azure Storage

**Role:** Event source.

Azure Storage is used as a source for storage-related events. Changes in
storage can generate events that are detected and routed through Event Grid.

**Purpose in this project:**
- Store project data or objects.
- Generate storage-related events.
- Act as an event source for Event Grid.

---

### 4. Azure Monitor / Application Insights

**Role:** Monitoring, logging and troubleshooting.

Azure Monitor and Application Insights are used to monitor the system and
record information about event processing and failures.

**Purpose in this project:**
- Monitor application activity.
- View logs and errors.
- Troubleshoot event-processing problems.
- Observe system performance.

---

## Overall Service Flow

Azure Storage
        ↓
Azure Event Grid
        ↓
Azure Functions
        ↓
Automation Action
        ↓
Azure Monitor / Application Insights
